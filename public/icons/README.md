# PWA Icons 说明

## 需要准备的图标尺寸

请准备以下尺寸的图标（PNG格式，建议使用正方形）：

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## 图标设计建议

1. **推荐尺寸**: 512x512 像素（最大）
2. **格式**: PNG 格式，带透明背景
3. **内容**: 可以是你的 logo、品牌标识或代表性的摄影作品缩略图
4. **颜色**: 建议使用简洁、醒目的设计，在深色和浅色背景下都清晰可见

## 在线工具推荐

你可以使用以下在线工具生成不同尺寸的图标：

1. **Favicon Generator**: https://realfavicongenerator.net/
2. **PWA Icon Generator**: https://www.pwabuilder.com/imageGenerator
3. **手动调整**: 使用 Photoshop 或在线工具如 Photopea (https://www.photopea.com/)

## 如何使用

1. 准备一个 512x512 像素的主图标
2. 使用在线工具生成所有需要的尺寸
3. 将生成的图标文件放在 `public/icons/` 目录下
4. 重新构建并部署网站

## 临时方案

如果暂时没有图标，网站仍然可以正常使用 PWA 功能，只是：
- 在手机主屏幕上会显示默认的浏览器图标
- 建议尽快添加品牌图标以提升专业度
